Privacy policy

Last updated: 5 October 2026

Who we are

Big Things Small is a YouTube channel of animated explainer videos (youtube.com/@BigThingsSmall). This policy covers this website and the "Big Things Small uploader", a small private tool the channel uses to manage its own videos.

This website

This website does not use cookies, does not ask for any personal information, and does not run analytics. It is hosted on GitHub Pages, which may keep basic technical logs (such as IP addresses) as described in GitHub's own privacy statement.

The Big Things Small uploader

The uploader is used only by the channel owner, to manage the channel's own YouTube videos. It is not offered to the public.

  • What it accesses: with the owner's permission, through Google sign-in, it uses the YouTube Data API to read the channel's list of uploads and to set the title, description, tags, thumbnail and settings of the channel's own videos.
  • What it stores: a sign-in token, kept only on the channel owner's own computer. It does not store or copy any other YouTube or Google data.
  • Sharing: no data is sold, shared with or sent to anyone else.
  • Removing access: access can be removed at any time at myaccount.google.com/permissions.

The uploader uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's Privacy Policy applies.

Contact

Questions about this policy: contact the channel through the "About" section of our YouTube channel.
